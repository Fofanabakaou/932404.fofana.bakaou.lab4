# Лабораторная работа №4 — Основы JavaScript

Вариант 20 — Футуролог и концепт-художник (прогнозируемый рост в %)

## Описание
Скрипт script.js анализирует массив прогнозов роста технологий/рынков (в %).
Запрашивает имя пользователя через prompt, выводит приветствие с результатами
через alert, и дополнительную статистику в консоль.

## Функции
- findMax — находит максимальный прогноз
- filterHighGrowth — фильтрует прогнозы выше 20%
- calculateSum — считает сумму прогнозов
